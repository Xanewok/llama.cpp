## A. Package 54: defect review and decisive falsifier

**D:** Reviewed `a1fff47fc` and `2efa6f8dc`, including the loaders, shared-memory layout, softmax, output stores and stream-K fixups. The evidence below does not establish a defect. Numerical drift is plausible: the selector changes the old vector route to grouped MMA; Q is scaled and converted to f16, K/V are dequantized to f16, and the served MMA VKQ accumulator is half2. This is a precision change as well as reduction reassociation. It does not guarantee identical target probabilities.

| Concern | Source evidence and conclusion (D unless stated) |
|---|---|
| Eligibility and calls | `ggml/src/ggml-cuda/fattn.cu:183` checks q8_0 K/V, a mask, `Q->ne[1] == 1`, zero bias/softcap, aligned strides and KV length divisible by `FATTN_KQ_STRIDE`. Dispatch at `:445` selects `<256,256,1,8,Q8_0>` for the served head dimension. Target one-row work can use it, including a one-row prefill tail or target decode/catch-up. | Padding and stale rows | `src/llama-kv-cache.cpp:1350` rounds the occupied physical extent up to KV padding; `:1758` marks the unused suffix `-INFINITY`. Finite, correctly quantized garbage is the appropriate first stale-row test. |

**M/D:** Recorded model metadata is M head count 24, KV head count 4, K/V head dimensions 256 (`2026-10-09-s10-depth-iq4/canary-a3/0-s10/server.log:125`). The package's `EVIDENCE.md` reports passing long-KV q8 operation checks, including GQA6; those are useful prior tests, not a padding-history proof. `tests/test-backend-ops.cpp:8384` already supports quantized, permuted KV views and has a default NMSE tolerance D `5e-4`; the added one-row tests in `a1fff47fc` mainly use KV depth D 2048. Do not repeat only those shapes.

**G: cheapest decisive kernel falsifier, designed but not added to the CUDA suite here.** Extend `test_flash_attn_ext::initialize_tensors()` / its view builder, rather than adding another kernel harness:

- D logical tensors: Q f32 `[256,1,24,1]`, K/V q8_0 `[256,Npad,4,1]`; per-GPU tensor split is D Q `[256,1,12,1]`, K/V `[256,Npad,2,1]`. Mask is f16 `[Npad,1,1,1]`, zero on visible keys and `-INFINITY` elsewhere. No sink, bias or softcap. K/V head stride must match the served D 102400-cell allocation, not an artificially packed `Npad` head stride; use permutation `{0,2,1,3}` for the cache-like view.
- D depth bases: 8192, 32768, 90112. G boundary cases: visible count `D-1`, `D`, `D+1`, `D+5`, `D+64`; `Npad = ceil(visible/4096)*4096`. This includes the newly padded blocks immediately after each scored boundary, rather than testing only exact multiples. All rows have valid q8_0 encodings and finite dequantized values.
- G primary invariant: identical active rows/Q/mask, change only masked K/V rows from zero to deterministic finite garbage. Require **byte-identical f32 output within each route** and finite output, on each GPU. Keep the same padded dimensions and stream-K partition. This can falsify a stale-row/mask bug without token sampling or a numerical tolerance.
- G cross-route check: ON, `GGML_CUDA_Q8_DECODE=0`, and a CPU f32 reference on the same dequantized inputs. Start with NMSE `<=1e-6` and max absolute error `<=2e-3` for bounded `[-1,1]` Q/K/V; record actual errors, not just pass/fail. These proposed bounds are stricter than the existing suite and are not a proven worst-case bound on f16 MMA. Failure of this bound alone means investigate precision; failure of padding independence is a correctness defect.
- G negative control: replace one masked suffix entry with zero mask and put a deliberately dominant finite K plus a distinct V there. Require a visible output change above the proposed absolute-error bound. Also run the existing `test_flash_attn_ext_large_logits` style Q scale to exercise max rescaling, and a tail with only one visible key to exercise empty stream-K partitions. NaN poisoning is a separate robustness case; both routes failing it is not package-specific.
